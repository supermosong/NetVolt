A — Auto-Playing Packet Flow

Glowing dots (packets) travel continuously along a line: Device → Router → Modem → Internet → back. No clicks needed. Labels and a short description appear below each node.

  • Always moving — draws the eye
  • Passive — no interaction required
  • Best for showing "data is always flowing"

B — Step-by-Step Click-Through

The user clicks "Next" to advance through 4–5 steps. Each step highlights the active node, dims the others, and shows a short educational description below.

  • User controls the pace
  • Teaches at each stage
  • Best for beginners who want to understand each part

C — Auto-Advance with Pause/Play

The animation auto-plays through each segment in sequence (Device→Router→Modem→Internet) with a glowing packet and description. User can pause, rewind, or click a node to jump to that step.

  • Best of both: passive watching + active exploration
  • Progress dots show current step
  • Most engaging — recommended
